Mihomo Core · Self-hosted

轻量自托管的 Mihomo 管理面板

3m-ui 帮你在 Linux 服务器上管理入站节点、用户与订阅、流量与告警、多机节点与安全配置下发。 默认走稳定版通道，安装与更新脚本开箱即用。

开始安装 下载 Release 文档站 查看源码
一键安装（Linux） 
curl -fsSL https://raw.githubusercontent.com/kazeyukiro/3m-ui/main/scripts/install.sh | sudo sh

核心能力

围绕 Mihomo Listener 与用户订阅设计，覆盖从建节点到客户端下发的完整链路。

◈

节点 / Listener

多协议入站、REALITY 目标扫描、证书与自签管理，配置校验后安全应用。

◎

用户与订阅

流量 / 到期 / IP·HWID 限制；Mihomo YAML、URI Base64、sing-box 等格式下发。

⬡

运维友好

安装 / 更新 / 重置密码 / 改端口；Telegram 告警；多机节点与合并订阅。

安装与升级

推荐在干净的 Ubuntu / Debian 等 Linux 主机上以 root 执行。安装完成后默认面板端口为 8080。

1

运行安装脚本

使用上方一键命令，自动拉取当前稳定版二进制与配套脚本。

2

保存初始密码

首次安装会打印一次性管理员密码（用户名一般为 admin），请立即保存并在首次登录后修改。

3

打开面板

浏览器访问 http://服务器IP:8080/。之后可用 3m-ui 菜单管理服务。

更新到最新稳定版 
sudo 3m-ui update --stable
# 或指定版本
sudo 3m-ui update v1.0.2
忘记密码时：在服务器执行 3m-ui → 选择「重置管理员密码」，会生成新随机密码并要求下次登录改密。
