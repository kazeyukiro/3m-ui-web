Mihomo · Self-hosted

Manage Mihomo nodes and subscriptions with ease

3m-ui is a lightweight web panel for Linux servers: inbound nodes, users and traffic, client configs, multi-node ops and alerts — install once, keep using it.

One-click install Read the docs GitHub
Linux install
curl -fsSL https://raw.githubusercontent.com/kazeyukiro/3m-ui/main/scripts/install.sh | sudo sh

Built for operators

From listeners to client subscriptions in one flow. Stable channel by default; scripts cover install, update and recovery.

Nodes & protocols

Manage Mihomo inbound listeners across common protocols and REALITY targets.

  • Create / edit / clone and templates
  • Validate then apply safely
  • Runtime status and connectivity checks

Users & subscriptions

Bind nodes per user, control traffic and expiry, export multiple client formats.

  • Mihomo YAML / URI / sing-box
  • HWID and subscription info page
  • Cross-node merged subscriptions

Panel ops

Install, update, change port, reset password; Telegram alerts and backups.

  • 3m-ui management menu
  • Stable and pre-release channels
  • Docker and native installs

Three steps

Use a clean Ubuntu / Debian host as root. Default panel port 8080.

1

Run the installer

Fetches the current stable binary, scripts and checksums.

2

Save the initial password

A one-time admin password is printed (user is usually admin). Change it after first login.

3

Open the panel

Visit http://SERVER_IP:8080/. Manage the service with the 3m-ui menu afterward.

Update
sudo 3m-ui update --stable
