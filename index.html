Mihomo · Self-hosted

轻松管理你的 Mihomo 节点与订阅

3m-ui 是面向 Linux 服务器的轻量 Web 面板：创建入站、管理用户与流量、下发客户端配置，并支持多机与告警——安装一次，长期好用。

一键安装 阅读文档 GitHub
Linux 安装
curl -fsSL https://raw.githubusercontent.com/kazeyukiro/3m-ui/main/scripts/install.sh | sudo sh

为运维设计的核心能力

从 Listener 到客户端订阅，一条链路打通；默认稳定版通道，脚本可安装、可更新、可恢复。

节点与协议

管理 Mihomo 入站 Listener，覆盖常用协议与 REALITY 目标选择。

  • 创建 / 编辑 / 克隆与模板
  • 配置校验与安全应用
  • 运行状态与连通性诊断

用户与订阅

按用户绑定节点，控制流量、到期与设备限制，并下发多种客户端格式。

  • Mihomo YAML / URI / sing-box
  • HWID 与订阅信息页
  • 跨机合并订阅

面板运维

安装、更新、改端口、重置密码；Telegram 告警与备份恢复。

  • 3m-ui 管理菜单
  • 稳定版 / 测试通道
  • Docker 与原生安装

三步开始

推荐在干净的 Ubuntu / Debian 主机上以 root 执行。默认面板端口 8080。

1

运行安装脚本

自动拉取当前稳定版二进制、脚本与校验文件。

2

保存初始密码

首次安装会打印一次性管理员密码（用户名一般为 admin），请立即保存并在登录后修改。

3

打开面板

访问 http://服务器IP:8080/。之后用 3m-ui 管理服务与更新。

更新
sudo 3m-ui update --stable
