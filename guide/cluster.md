# 多机节点

登记远端 3m-ui 面板、健康检查，并把远端节点**镜像合并**进本机用户的订阅；也可按名称将本机节点**推送**到远端（默认关闭，可改名/改端口）。

## 概念

- **远端面板**：基址 URL + API 凭证  
- **节点镜像**：远端 Listener 出现在本机订阅输出中  
- **推送**：把选中的本机节点同步到远端（需在设置中启用相关能力）

## 完整流程

1. **登记远端**：「多机节点」页 → 添加节点，填写面板 URL。登记后点 **Login** 用远端管理员账号换取 JWT（后续同步/推送都依赖它；返回 401 时重新 Login 即可）。
2. **同步镜像**：点 **Sync**，远端 Listener 会以「镜像」形式缓存到本机（含分享链接与客户端 YAML）。
3. **绑定给用户**：进入「用户管理」→ 选中用户 → **绑定节点**，弹窗下半部分 **远程集群节点** 多选框里勾选要分发的镜像，保存。
4. **用户订阅**：该用户的订阅链接现在同时包含本机节点与远端镜像节点。

## 订阅合并

已绑定用户可在同一份订阅里同时拿到本机节点与远端镜像节点，覆盖全部导出格式：

| 格式 | 入口 |
| --- | --- |
| Clash / Mihomo | 订阅链接默认输出，或 `?target=clash` |
| v2ray / BASE64 | `?target=v2ray`（v2rayN / v2rayNG 自动识别） |
| sing-box | `?target=singbox` |
| Loon / Surge / Quantumult X | `?target=loon` / `surge` / `quanx` |

镜像节点名带 `R<远端ID>-` 前缀，避免与本机节点重名。只绑了镜像、没有本机节点的用户同样能拿到全部格式的订阅。

## 停用与删除

- **停用远端**：镜像立即从所有订阅撤下，用户绑定关系保留；重新启用后节点自动恢复，无需重新绑定。
- **删除远端**：镜像与相关用户绑定一并清除，订阅不再包含该远端的任何节点。

## 注意

- 远端建议 HTTPS，并使用权限受限的 API Token  
- 健康检查会跳过不可达远端，避免一台挂掉导致整份订阅为空  
- 推送前确认端口与名称冲突策略，避免覆盖远端已有节点  
- 绑定弹窗中标记「远端已禁用」的镜像暂不参与订阅，勾选前先启用对应远端  

具体按钮与字段以当前面板「多机 / 集群」页面为准。
