# 用户与流量

### 一键创建

用户页 → **一键创建**：用户名可空（自动生成），自动生成密码与 UUID，可选绑定全部本地节点。明文密钥只在弹窗中显示一次。

API：`POST /api/v1/users/quick`

### 流量与限制

- 总流量上限、到期时间、IP 限制、订阅拉取次数限制等
- **按节点分别计量** 时，展示与扣减会考虑节点倍率
- 在线状态依赖内核连接信息，短暂离线/重载属于正常现象

### 设备与安全相关

以当前版本面板字段为准；若某项已砍掉或变更，以 Release 说明为准。
