# 用户与流量

### 一键创建

用户页 → **一键创建**：用户名可空（自动生成），自动生成密码与 UUID，可选绑定全部本地节点。明文密钥只在弹窗中显示一次。

API：`POST /api/v1/users/quick`，请求体 `{ "username"?: string, "bind_all_listeners"?: boolean, "remark"?: string }`。响应包含 `{ user, password, uuid }`。完整创建仍为 `POST /api/v1/users`。OpenAPI：`GET /api/v1/openapi.yaml`。

### 流量与限制

- 总流量上限、到期时间、IP 限制、订阅拉取次数限制等相关字段
- **按节点分别计量** 时按各节点倍率计费
- 在线状态依赖内核连接信息，重载期间短暂离线属于正常现象

### 限制字段

| 字段 | 含义 |
|------|------|
| `ip_limit` | `0` = 不限同时在线来源 IP。设置后面板约每 **5 秒**轮询一次 Mihomo 连接并关闭超额 IP（并非在握手时阻断）。 |
| `sub_pull_limit` | `0` = 不限。按 **滚动 24 小时**统计成功订阅下载次数；超限返回 **429**。 |

### 按节点流量与倍率

每个节点有 **流量倍率**（默认 1）。该节点原始字节 × 倍率计入用户配额（`traffic_used`）。

用户页 → 节点流量操作可查看各节点原始与计费用量。API：`GET /api/v1/users/{id}/node-traffic`。

### 用户字段（摘要）

| 字段 | 说明 |
|------|------|
| 用户名 | 唯一；硬删除后名称可复用 |
| 备注 | 显示名 / 订阅标题兜底 |
| 启用 | 关闭后鉴权与订阅均失败 |
| 流量上限 | 字节；`0` = 不限 |
| 已用流量 | 上下行累计（适用时已计入倍率） |
| 到期时间 | 可选；周期/续期相关字段以当前 UI 为准 |

设备与安全相关选项以当前版本面板字段为准；若某项已砍掉或改名，以 Release 说明为准。
