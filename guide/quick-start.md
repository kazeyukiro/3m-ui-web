# 快速开始

仪表盘会显示主机资源，以及 **面板 / Mihomo 内核** 进程的 CPU 与内存占用。

1. 在干净的 Linux 主机上用一键脚本安装。
2. 打开面板，使用安装时打印的初始账号登录。
3. 按提示修改管理员密码。
4. 创建节点（Listener）：**一键创建** 只需协议 + 名称；高级选项用完整表单。保存后会先写入数据库，Mihomo 稍后在后台重载。
5. 创建用户、绑定节点，复制订阅链接。

更多说明见 [安装](/guide/install) 与 [节点](/guide/listeners)。
