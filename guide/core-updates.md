# 核心更新

管理员可在 **内核 → 检查更新** 中选择官方稳定版或预发布版 Mihomo，或 **恢复上一版本** 回到已保存的二进制。这与面板程序本身的更新相互独立。检查更新**不会**自动安装；需手动确认。

会查询最近约 30 个 GitHub Release，排除草稿以及缺少 SHA-256 摘要的产物。完整安装支持的 Linux 架构一般为 **amd64**、**arm64**。

## 行为说明

- 更新器仅从官方 Mihomo Release 资源下载，并校验摘要  
- 安装新内核前会尽量保留可回退的上一份二进制  
- 更换内核后应重新 **生成 → 校验 → 应用** 配置，确认核心可启动  

## 稳定版与预发布

- **稳定版**：默认安装与更新通道，与面板发行说明中的 pinned 版本一致  
- **预发布**：需在界面中主动选择；见 [预发布通道](./dev-channel)  

## 与面板更新的关系

- `3m-ui update` / 一键安装脚本：更新**面板**（及发行包内配套内核策略）  
- 面板内「内核更新」：单独更换 **Mihomo** 二进制  

二者不要混淆。出问题优先恢复上一内核，或重装已知可用的发行包。
