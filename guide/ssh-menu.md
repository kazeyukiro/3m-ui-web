# SSH 管理菜单

在服务器上直接执行 `3m-ui` 即可打开管理菜单。面板打不开时，它是最常用的救援入口。

```bash
3m-ui            # 交互式菜单
3m-ui help       # 命令行用法
```

菜单是传统的**编号文本菜单**：输入数字后回车。原有的 `a`（卸载）与 `0`（退出）继续可用。

## 菜单项

| 2 | 更新到最新 | 16 | SSH 救援重置面板配置 |
| 3 | 更新到指定版本 | 17 | 健康检查 |
| 4 | 运行状态 | 18 | BBR |
| 5 | 启动 | 19 | 更新 Geo |

## SSL 证书助手（acme.sh）

菜单 **21** 可以真正调用 [acme.sh](https://github.com/acmesh-official/acme.sh) 申请、部署和续期证书：

| # | 功能 |
|---|------|
| 1 | 安装 / 更新 acme.sh |
| 2 | 申请证书（standalone，需 80 端口空闲） |
| 3 | 申请证书（DNS API，不占 80 端口） |
| 4 | 安装证书到 3m-ui 并重载面板 |
| 5 | 证书列表 |
| 6 | **查看证书详情** |
| 7 | 续期证书 |
| 8 | 打印命令（供手动执行） |
| 9 | 返回 |

证书安装目录为 `/etc/3m-ui/certs/`（`域名.key` 与 `域名.crt`）。

### 关于许可证

acme.sh 是 **GPL-3.0**，3m-ui 是 **EPL-2.0**，两者不兼容。因此 3m-ui **不会内置 acme.sh 源码**，
而是在菜单里驱动你机器上独立安装的 acme.sh（默认 `~/.acme.sh/acme.sh`），需要时由菜单帮你安装。
这样既不产生许可证冲突，也方便 acme.sh 独立升级。

面板自身的 HTTPS 仍推荐使用面板内「系统设置 → SSL」的内置 ACME；这里的集成主要用于给节点或反向代理签发证书。

### 选择证书颁发机构（CA）

申请证书（菜单 2 或 3）时会先让你选 CA：

| 选项 | 说明 |
|------|------|
| Let's Encrypt | 使用最广；不带邮箱也可申请 |
| ZeroSSL | **acme.sh v3 的默认 CA**，需要用邮箱注册账户 |
| Buypass | 挪威 CA，证书有效期 180 天 |
| SSL.com | 商业 CA |
| Google Trust Services | Google 的 CA |

选「返回」则沿用 acme.sh 当前的默认 CA（v3 起为 ZeroSSL）。

### 查看证书详情

菜单 6 会显示证书的主题、颁发者、有效期起止，并提示是否在 30 天内到期
（用 `openssl x509` 读取；若系统没有 openssl 会给出提示）。随后可以选择查看实际内容：

| 选项 | 说明 |
|------|------|
| 证书 PEM（含公钥） | 打印完整的证书 PEM 文本 |
| 公钥 PEM | 用 `openssl x509 -pubkey` 从证书提取公钥 |
| 私钥 PEM | 打印私钥 —— **会先警告并要你确认**（默认否） |

私钥会完整显示在屏幕上，并可能留存于终端回滚缓冲或日志中，所以默认不显示；
未确认时不会输出任何私钥内容。

### 安装源

首次安装时会让你选择来源：

| 选项 | 说明 |
|------|------|
| 官方 `get.acme.sh` | 网络通畅时的默认选择 |
| Gitee 镜像 | **中国大陆服务器推荐**；GitHub 归档经常超时（acme.sh 自身也会提示 Install-in-China） |

已经安装过时直接执行升级，不再询问来源。

### 自动续期

acme.sh 依赖 crontab 自动续期证书。若系统没有 `crontab`，安装会被拒绝；
此时菜单会询问是否用 `--force` 继续 —— **但证书将不会自动续期**，
你需要自行添加定时任务每天执行 `acme.sh --cron`。建议先安装 cron：

```bash
# Debian / Ubuntu
apt install -y cron
# RHEL / CentOS
yum install -y cronie
```

## 语言切换

菜单支持中文与英文两套**完全独立**的文案（不再是中英混排在同一行）。

```bash
3m-ui lang           # 查看当前语言
3m-ui lang zh        # 中文
3m-ui lang en        # English
3m-ui lang auto      # 忽略已保存的设置，按系统 locale 重新检测
```

也可以选择菜单 **24. 语言 / Language**，或用环境变量临时覆盖：

```bash
THREE_M_UI_LANG=en 3m-ui
```

优先级：**环境变量 > 已保存的设置 > 系统 locale 自动检测**。
设置保存在 `/etc/3m-ui/menu.conf`，**不会写入 `config.yaml`**（后者属于面板程序）。

## 终端控制中心（TUI）

面板二进制内置了一个终端控制台：多栏界面（顶栏 + 左侧导航 + 内容区 + 模态弹窗），纯键盘操作。

```bash
3m-ui tui
```

（等价于直接运行面板二进制 `/usr/local/lib/3m-ui/3m-ui-bin tui`；`3m-ui` 是统一管理入口。）

四个栏目：

| 栏目 | 内容 |
|------|------|
| 概览 | 版本、运行状态、面板端口、监听地址、公开地址、开机自启、证书数量 |
| 服务 | 启动 / 停止 / 重启 / 开机自启（弹窗选择）/ 查看日志 |
| 证书 | 读取 `/etc/3m-ui/certs/` 下的证书，显示到期时间与剩余天数（30 天内转黄、已过期转红） |
| 系统 | 版本、git commit、构建时间、配置文件与数据库路径 |

### 键位

| 按键 | 作用 |
|------|------|
| `←` `→` | 在侧边栏与内容区之间切换焦点 |
| `↑` `↓`（或 `k` `j`） | 移动选择 |
| `Enter` | 进入栏目 / 执行选中项 |
| `0`–`9` | 数字直达条目 |
| `r` | 刷新 |
| `Esc` | 关闭弹窗 / 退回侧边栏 |
| `q` | 返回 / 退出 |

停止、重启这类操作会先弹确认框，且默认停在「取消」。

### 运行环境

控制台需要**真实终端**：被管道调用或 `TERM=dumb` 时它会直接报错退出，不会把转义序列写进日志或 cron 输出。界面语言跟随 `THREE_M_UI_LANG`（`zh` / `en`）或系统 locale。

## 不暴露 Web 面板时收敛攻击面

面板监听地址由 `/etc/3m-ui/config.yaml` 里的 `server.listen` 决定：为空或 `0.0.0.0` / `::` / `*` 时监听全部网卡，填具体 IP 则只绑该地址。

若日常操作都在 SSH / 控制台里完成，可以把管理端只绑到本地，同时让客户端订阅继续公网可达：

```yaml
server:
  port: 8080
  listen: 127.0.0.1      # 管理界面与 API 只监听本地
  sub_port: 8081         # 大于 0 且与 port 不同时，订阅走独立端口
  sub_listen: 0.0.0.0    # 订阅继续对客户端开放
```

需要 Web 时用 SSH 隧道：`ssh -L 8080:127.0.0.1:8080 user@server`，然后打开 `http://127.0.0.1:8080`。

注意：

- 改完需要 `3m-ui restart` 生效。
- 菜单 16 的 `reset-config --panel` 会**清掉 `listen`**，面板会重新监听全部网卡 —— 这是救援流程的刻意行为，救援后记得重新设置。
- 只绑本地不等于不用防火墙，安全组 / 防火墙仍建议限制来源 IP。
- 这样 SSH 就成了唯一入口，务必只使用密钥登录并禁用密码登录。

## 非交互命令

菜单之外的子命令行为完全不变，可安全用于脚本与 cron：

```bash
3m-ui status | start | restart | stop | enable | disable
3m-ui logs [-f] | version | healthcheck
3m-ui backup | restore <snapshot.tar.gz>
3m-ui reset-admin
3m-ui reset-config --panel --yes     # 重置 listen/SSL，重启后 HTTP 访问
3m-ui reset-config --all --yes       # 全量重置（含 public_url）
3m-ui update [vX.Y.Z|pre] | channel stable|pre [--update]
```

## 说明

- 放行防火墙端口前会二次确认，避免误扩大公网暴露面。
- 面板配置写错导致 Web 打不开时，用 **16. SSH 救援重置面板配置** 恢复为 HTTP 访问。
