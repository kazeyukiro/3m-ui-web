# 按节点流量与倍率

## 流量倍率

每个 Listener 可设置 **流量倍率**（`traffic_multiplier`）。计入用户配额的用量为：

```text
billed = actual_bytes × node_multiplier
```

例如倍率 `1.5`：实际传输 1 GiB 会按 1.5 GiB 计入 `traffic_limit`。计费值按四舍五入取整。

## 行为说明

- 倍率默认 `1`；`<= 0` 按 `1` 处理，大于 `100` 会被限制为 `100`
- 面板按节点统计会分别展示原始用量与计费用量（可获取时）
- 修改倍率只影响**之后的**计费；历史记录同时保存原始字节与计费字节，不会因修改倍率而重算
- 修改倍率不会改写用户已消耗的配额

## 节点流量统计

节点与用户流量统计依赖 Mihomo 连接数据。重载内核或协议字段不完整时，可能出现短暂无数据；确认 Listener 配置与用户绑定后，再观察仪表盘 / 用户页统计。

## 使用建议

- 昂贵的中转节点设较高倍率；本地 / 免费容量的节点保持 `1`
- 配合用户流量上限与到期时间，可实现套餐式配额
