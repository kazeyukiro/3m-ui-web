# Quick start

The dashboard shows host resources and **panel / Mihomo core** process CPU and memory.

1. Install with the one-click script on a clean Linux host.
2. Open the panel and sign in with the printed credentials.
3. Change the admin password when prompted.
4. Create a listener (node) — **Quick create** only needs protocol + name; full form for advanced options. Saves return after the DB write; Mihomo reloads in the background shortly after.
5. Create a user, bind the node, copy the subscription URL.

See [Install](/en/guide/install) and [Listeners](/en/guide/listeners) for details.
