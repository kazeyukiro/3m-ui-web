# AI install prompt

Use the English prompt file with your AI assistant to install or recover 3m-ui safely.

Download / copy from the repository:

- `docs/ai-install-prompt.en.txt` (English)
- `docs/ai-install-prompt.zh.txt` (Chinese)

Also see [Install](./install) and https://3m-ui.top/en/guide/install

The prompts only guide the official `scripts/install.sh` one-line installer; downloads are verified with `SHA256SUMS`. Do not let an assistant rewrite download URLs, append unknown flags, or switch to third-party mirrors.

Full install, upgrade, and recovery: [Install](./install).
