System settings

Theme, subscription page options, Telegram, public URL and related panel options live under Settings (grouped sections).

面板 系统设置 聚合运营向配置（多数存数据库，不必改 config.yaml）。

面板 / NAT（端口与公网 URL）

  • 面板端口、监听地址、面板公网 URL
  • 写入 /etc/3m-ui/config.yaml 的 server.port / listen / public_url
  • 修改端口或监听后必须重启 3m-ui 服务

环境变量与 API 说明见 NAT与面板端口。
