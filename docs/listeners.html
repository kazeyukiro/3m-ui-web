Listeners (nodes)

Create inbound listeners from the panel. Supported protocols follow the Mihomo listener model (VLESS, VMess, Trojan, Shadowsocks, Hysteria2, TUIC, and more).

One-click create

Use Quick create when you only need a protocol and a name. The panel allocates a free port and fills credentials / REALITY–TLS defaults. Full form create is still available for advanced fields.

How saves work

Create / update / delete write the panel database first and return success immediately. Mihomo config application is debounced in the background (about 400ms), same idea as user credential sync. A successful UI response does not mean the core has finished reloading yet — wait a moment, then use runtime status / connectivity checks. Activation failures are logged and do not roll back the panel record; fix the config and reload if needed.

API: POST /api/v1/nodes, POST /api/v1/nodes/quick (aliases under /listeners). OpenAPI: GET /api/v1/openapi.yaml.

Batch certificate

Select multiple nodes and apply one TLS certificate (PEM body, allowlisted file paths such as Let's Encrypt, or reuse panel SSL). API: POST /api/v1/nodes/batch/certificate.

对应 Mihomo 的 inbound / listener，在面板中称为节点。

创建与编辑

节点管理 中可配置：

  • 名称、协议、端口、绑定地址
  • 启用 / 禁用
  • 协议相关字段（UUID、密码、路径、SNI、REALITY 等）
  • TLS 证书路径或由上层反代终止 TLS
  • Public Host / Public Port：客户端看到的地址（CDN、多 IP、IPv6 时很有用）

一键创建

只需选择协议并填写名称即可创建。端口自动分配，凭据与 REALITY/TLS 默认值由服务端生成。完整表单仍可用于精细配置。

保存如何生效

创建 / 更新 / 删除会先写入面板数据库并立即返回成功，再在后台约 400ms 防抖后应用 Mihomo 配置（与用户凭据同步同一思路）。界面提示成功不代表内核已重载完成，请稍等片刻，再用运行时状态 / 连通性检查确认。内核应用失败会写日志，不会回滚面板中的节点记录；修好配置后可再重载。

API：POST /api/v1/nodes、POST /api/v1/nodes/quick（亦有 /listeners 别名）。OpenAPI：GET /api/v1/openapi.yaml。

在 配置引擎 中仍可将「生成 / 校验 / 应用」分开操作：生成只预览 YAML，不会写盘；确认后再应用。误操作可用回滚恢复上一份配置。

协议

常见支持（以当前版本协议表为准）：

  • VLESS / VMess / Trojan / Shadowsocks
  • Hysteria2 / TUIC / 其它面板列出的类型

具体字段随协议变化，未知字段不要手改数据库。

搜索与批量

列表支持按名称、协议、端口、绑定地址搜索（若版本已启用）。

与用户的关系

用户可绑定一个或多个 Listener；订阅与分享链接只包含其有权使用的入站。

配置引擎

配置 页面可预览生成的 Mihomo YAML、做可视化或高级编辑。生产环境建议以面板表单为主，减少手工改 YAML 导致的不一致。

批量应用证书

节点列表可多选后一键写入证书与私钥（PEM、文件路径或复用面板 SSL）。API：POST /api/v1/nodes/batch/certificate，body 含 ids 与 PEM 或 cert_file/key_file 或 from_panel_ssl。

TLS 自签证书

需要服务端证书且未填写 PEM 时，面板会签发自签证书（标记 Organization=3m-ui），并写入：

/var/lib/3m-ui/listener-certs/{id}.crt / .key

  • 更新面板二进制时，会尽量从该目录恢复，避免无故换证
  • 客户端订阅/URI 对面板自签会带上 skip-cert-verify / insecure=1
  • Reality 或完整 TLS 包装（shadow-tls / jls 等）不会强制自签
  • 备份时请包含 listener-certs/（见 备份与恢复）
