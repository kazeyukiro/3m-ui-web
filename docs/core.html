Core

3m-ui manages a pinned Mihomo binary. Start, stop, restart and update from the panel Core page or via 3m-ui service commands.

面板通过本地 Mihomo 进程管理代理核心。

操作

操作 说明
状态 是否运行、版本、PID 等
启动 使用当前生成配置启动
停止 结束进程
重启 停止后再启动

配置应用流程概要：

编辑 → 预览 → 校验 → 备份 → 应用 → 启动/重启 → 健康检查
                                      ├ 成功：保留
                                      └ 失败：回滚配置

首次启动若尚无配置文件，可能软失败并提示，而不是整面板崩溃。

路径

在 config.yaml 的 mihomo 段配置：

  • 二进制路径
  • 配置文件路径
  • 工作/数据目录（GeoIP 等）

系统设置 中可一键更新 MetaCubeX GeoIP / GeoSite 到 Mihomo 数据目录。

日志

运行日志 页查看面板与核心相关输出；系统级用：

journalctl -u 3m-ui -f
